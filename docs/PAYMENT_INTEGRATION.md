# Pars Linux Boot Repair — Bağış, Destek ve Finansal Sürdürülebilirlik (PAYMENT_INTEGRATION.md)

Bu doküman, açık kaynaklı **Pars Linux Boot Repair** projesinin uzun vadeli sürdürülebilirliğini sağlamak amacıyla topluluk bağışları, kurumsal sponsorluklar ve isteğe bağlı destek modellerini tanımlar.

---

## 1. Açık Kaynak Felsefesi ve Finansal Model

Pars Linux Boot Repair; **GNU GPLv3** lisanslı, %100 özgür ve açık kaynaklı bir sistem yazılımıdır.
- **Kesin İlke**: Temel yazılım işlevleri asla bir ödeme duvarı (paywall) arkasına alınamaz; reklam veya casus yazılım (adware/spyware) barındıramaz.
- **Finansmanın Amacı**:
  1. Çeşitli UEFI anakartlar, BIOS sürümleri, NVMe/SATA/eMMC donanım test laboratuvarının sürekliliği.
  2. Paket deposu, derleme sunucuları ve CI/CD altyapı maliyetlerinin karşılanması.
  3. Açık kaynak geliştirici topluluğuna katkı bursları sağlamak.
