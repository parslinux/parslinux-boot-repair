# Güvenlik Politikası

## Desteklenen Sürümler

| Sürüm | Destek Durumu |
| :--- | :--- |
| 1.2.x | :white_check_mark: Destekleniyor |
| < 1.2.0 | :x: Desteklenmiyor |

## Güvenlik Açığı Bildirimi

Pars Linux Boot Repair doğrudan disk bölümleri, kök dosya sistemleri (`rootfs`), şifreleme anahtarları ve sistem önyükleme kayıtları üzerinde çalışır.

Yetki yükseltme, PolicyKit atlatma veya veri kaybına yol açabilecek bir güvenlik açığı tespit ederseniz:

1. **Lütfen halka açık issue açmayın.**
2. Detaylı açıklama ve yeniden üretim adımları ile birlikte **`security@parslinux.org`** adresine e-posta gönderin.
3. Bildiriminiz en geç 48 saat içinde incelenecek ve gerekli yamalar öncelikli olarak hazırlanacaktır.
